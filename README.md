# Qlick-BI-lab
📚 Academic Context

This project was developed as part of the Business Intelligence course.

📊 The objective was to:

-Design a Star Schema data model

-Load and transform data using Qlik Cloud

-Create analytical dashboards for sales performance

📊 The project demonstrates practical application of Business Intelligence concepts such as:

-Data modeling

-ETL processes

-KPI calculation

Dimensional modeling

Dashboard design
